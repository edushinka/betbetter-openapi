# Bet Better Free Sports Model API — OpenAPI 3.0 spec

The machine-readable spec for the free, no-key [Bet Better](https://betbetter.world) sports model API: win probabilities, fair odds and plain-English verdicts across 12 sports.

- **Live spec (canonical)**: https://betbetter.world/api/openapi.json
- **Human docs**: https://betbetter.world/api/
- **Python client**: [`pip install betbetter`](https://github.com/edushinka/betbetter-python)
- **MCP server for AI agents**: [`npx betbetter-mcp`](https://www.npmjs.com/package/betbetter-mcp)

Try it now, no key needed:

```
https://betbetter.world/mlb/picks?format=json
https://betbetter.world/nfl/prop-bets?format=json
https://betbetter.world/results?format=json
```

The feed carries the model's own numbers only — no bookmaker prices. Data licence **CC BY 4.0** with attribution to Bet Better (betbetter.world). Model estimates for research. Not betting advice. 18+. Gamble responsibly.
